# git-diff-helper.sh — Git 差分ヘルパー

RHEL 9.6 上で動作する、`git diff` の各種差分を **パラメータ指定ひとつ** で取得し、
**画面 / テキスト(.txt) / Markdown(.md) / Excel(.xlsx)** の 4 形態で出力するシェルスクリプトです。
あわせて、詳しい利用方法をまとめた **利用ガイド Excel（全シート Meiryo UI）** も追加出力します。

---

## 1. 特長

| 項目 | 内容 |
|------|------|
| 対応する差分 | ワークツリー⇔ステージ / ステージ⇔HEAD / ワークツリー⇔最新コミット / N個前のコミット / 特定コミット / 2コミット間 / コミット対話選択(ブランチ選択・ページャー付き) / ブランチ間 / リモート追跡ブランチ |
| 画面出力 | 色分け・罫線・**旧行番号／新行番号の併記**・ファイル別変化量バーグラフ |
| テキスト出力 | 画面と同一レイアウト（色なし）＋ 参考として生の `git diff` 出力 |
| Markdown 出力 | 表 ＋ ` ```diff ` ブロック構成。GitHub / GitLab / Backlog にそのまま貼り付け可能。生の `git diff` は折りたたみ（`<details>`）に格納 |
| Excel 出力 | 4 シート構成（サマリ／ファイル一覧／差分明細／コミット履歴）、追加行=緑・削除行=赤の色分け、ウィンドウ枠固定、オートフィルタ付き |
| 利用ガイド Excel | 9 シート構成（表紙・概要／セットアップ／モード一覧／オプション一覧／使用例／出力ファイル／レポートの見方／FAQ・トラブル対処／用語集）。**全シート Meiryo UI**、見出し帯・ゼブラ模様・枠固定・オートフィルタ・A4 横の印刷設定付き |
| 依存 | `git` / `bash` / `awk`(gawk) / `coreutils` / `tr` — いずれも RHEL 9 標準。xlsx 生成のみ `zip` または `python3` が必要（無い場合は自動的に CSV へフォールバック） |
| 外部ライブラリ | **不要**（openpyxl 等のインストールは不要。xlsx を素の XML + zip で生成） |

## 2. セットアップ

```bash
# 任意の場所に配置して実行権限を付与
chmod +x git-diff-helper.sh

# どこからでも使えるようにする場合（任意）
sudo cp git-diff-helper.sh /usr/local/bin/git-diff-helper
```

### 前提パッケージの確認

```bash
rpm -q git gawk coreutils zip     # zip が未導入なら以下で導入
sudo dnf install -y zip
```

> `zip` も `python3` も無い環境では、Excel 出力が自動的に CSV（UTF-8 BOM 付き・
> Excel でそのまま開ける形式）に切り替わります。明示指定する場合は `-x csv`。

## 3. 使い方

```bash
./git-diff-helper.sh -m <モード> [オプション] [-- <パス指定>...]
./git-diff-helper.sh -i [オプション]                 # 対話選択モード (ブランチ・コミット選択)
./git-diff-helper.sh --manual-only [-o <出力先>]     # 利用ガイド Excel のみ生成
```

### 3.1 モード一覧

| モード | 別名 | 比較内容 | 実行される git コマンド |
|--------|------|----------|--------------------------|
| `worktree` | `wt`, `unstaged` | ワークツリー ⇔ ステージ | `git diff` |
| `staged` | `cached`, `index` | ステージ ⇔ HEAD | `git diff --cached` |
| `head` | `latest` | ワークツリー ⇔ 最新コミット | `git diff HEAD` |
| `prev` | `last` | N個前のコミット ⇔ HEAD | `git diff HEAD~N HEAD` |
| `commit` | — | 指定コミットの親 ⇔ 指定コミット | `git diff <親> <指定>` |
| `commits` | `range` | 特定の2コミット間 | `git diff <from> <to>` |
| `select` | `pick`, `interactive` | ブランチ・コミット対話選択 (ページャー付き) | `git diff <from> <to>` |
| `branches` | `branch` | ブランチ同士 | `git diff <from>...<to>` |
| `remote` | `upstream` | リモート追跡ブランチ ⇔ HEAD | `git diff <upstream> HEAD` |

### 3.2 実行例

```bash
# ① まだ git add していない変更を確認
./git-diff-helper.sh -m worktree

# ② git add 済み・未コミットの変更を確認
./git-diff-helper.sh -m staged

# ③ 未コミットの変更をすべて（ステージ済み＋未ステージ）
./git-diff-helper.sh -m head

# ④ 直近1コミットで加えた変更 / 直近3コミット分
./git-diff-helper.sh -m prev
./git-diff-helper.sh -m prev -n 3

# ⑤ 特定コミットが加えた変更だけを見る
./git-diff-helper.sh -m commit -f a1b2c3d

# ⑥ 特定の2コミット間
./git-diff-helper.sh -m commits -f a1b2c3d -t f9e8d7c

# ⑦ ブランチを選択し、直近コミットをページ送りしながら2点間を比較 (対話モード)
./git-diff-helper.sh -m select
./git-diff-helper.sh -i

# ⑧ ブランチ同士（main から分岐後に feature 側で入った変更のみ＝三点比較）
./git-diff-helper.sh -m branches -f main -t feature/login
#    先端同士を単純比較したい場合
./git-diff-helper.sh -m branches -f main -t feature/login --no-merge-base

# ⑨ リモート追跡ブランチとの差分（upstream 自動判定）
./git-diff-helper.sh -m remote
#    比較先を明示指定
./git-diff-helper.sh -m remote -t origin/develop

# ⑩ 対象を絞り込む・出力先を変える
./git-diff-helper.sh -m head -o /var/tmp/diffrep -- src/ docs/README.md

# ⑪ 別リポジトリを対象にする（cd 不要）
./git-diff-helper.sh -m head -r /srv/git/myapp

# ⑫ Markdown だけを作る（課題管理システムへの貼り付け用）
./git-diff-helper.sh -m head --no-excel --no-text --no-screen

# ⑬ Markdown の差分行に旧／新の行番号を併記する
./git-diff-helper.sh -m head --md-linenos

# ⑭ 利用ガイド Excel（使い方マニュアル）だけを生成する
./git-diff-helper.sh --manual-only -o ./docs
```

### 3.3 主なオプション

| オプション | 説明 |
|-----------|------|
| `-i, --interactive` | コミット対話選択モードを起動 (ブランチ選択・ページャー付き) |
| `-f, --from <REF>` | 比較元（コミット / ブランチ / タグ / SHA） |
| `-t, --to <REF>` | 比較先（省略時は `HEAD`） |
| `-n, --back <N>` | `prev` モードで N 個前のコミットと比較（既定 1） |
| `-r, --repo <DIR>` | 対象リポジトリのパス（既定はカレントディレクトリ） |
| `-o, --outdir <DIR>` | 出力先ディレクトリ（既定 `./git-diff-report`） |
| `--prefix <NAME>` | 出力ファイル名の接頭辞（既定 `git-diff`） |
| `-U, --context <N>` | 差分の前後コンテキスト行数（既定 3） |
| `--merge-base` / `--no-merge-base` | 三点比較（`A...B`）/ 二点比較（`A B`）の切替 |
| `-w, --ignore-space` | 空白のみの差分を無視 |
| `--no-renames` | リネーム検出を行わない |
| `-x, --excel <FMT>` | `auto`（既定）/ `xlsx` / `csv` / `none` |
| `--no-excel` / `--no-text` / `--no-md` / `--no-screen` | 各出力を抑止 |
| `--md-linenos` | Markdown の差分行に旧／新の行番号を併記 |
| `--manual` / `--no-manual` | 利用ガイド Excel の出力を強制／抑止（既定は出力する） |
| `--manual-only` | 利用ガイド Excel だけを生成して終了（モード指定不要・git リポジトリ外でも可） |
| `--no-raw` | テキスト／Markdown 出力に生の `git diff` を含めない |
| `--summary-only` | 差分明細を出さずサマリのみ表示 |
| `--max-lines <N>` | 1ファイルあたりの明細表示行数上限（0=無制限。画面／テキスト／Markdown に適用） |
| `--excel-max-rows <N>` | 差分明細シートの最大行数（既定 100000） |
| `--ascii` / `--no-color` / `--color` | 画面装飾の制御 |
| `--pager` | 画面出力を `less -R` に流す |
| `-l, --list-modes` / `-h, --help` / `-V, --version` | 情報表示 |

> `--no-excel` または `-x none` を指定すると、利用ガイド Excel も併せて抑止されます。
> 明示的に `--manual` を付けた場合は常に出力します。

## 4. 出力内容

### 4.1 画面 / テキスト

```
────────────────────────────────────────────────────────────
  Git 差分レポート / Git Diff Report
────────────────────────────────────────────────────────────

 [ 実行条件 ]          … 日時・リポジトリ・ブランチ・HEAD・モード・実行コマンド
 [ 差分サマリ ]        … 変更ファイル数 / 追加行 / 削除行 / 差引 / 状態の内訳
 [ ファイル別サマリ ]  … No・状態・追加・削除・変化量バー・ファイル名
 [ 対象コミット一覧 ]  … コミット系モードのみ
 [ 差分明細 ]          … 旧行番号 │ 新行番号 │ ± 内容
```

差分明細は次の形式で、**変更前後の行番号が同時に読み取れる** ようになっています。

```
┌── [1/3] src/main.c
│   状態: 変更 (M)   追加: +10  削除: -2
│
│ @@ ハンク1   旧: 8行目から3行 → 新: 8行目から4行 @@  int main(int argc, char **argv) {
│      8 │      8 │       }
│      9 │      9 │       return EXIT_SUCCESS;
│        │     10 │ + 追加された行
│     10 │        │ - 削除された行
└────
```

出力ファイル:

```
<出力先>/<接頭辞>_<モード>_<YYYYMMDD_HHMMSS>.txt
```

### 4.2 Markdown（md）

`<出力先>/<接頭辞>_<モード>_<YYYYMMDD_HHMMSS>.md`

見出し・表・コードブロックで構成された、そのまま共有できるレポートです。

| セクション | 内容 |
|-----------|------|
| 1. 実行条件 | 日時・リポジトリ・ブランチ・HEAD・モード・実行コマンド（表形式） |
| 2. 差分サマリ | 変更ファイル数 / 追加行 / 削除行 / 差引 / 状態の内訳 |
| 3. ファイル別サマリ | No・状態・追加・削除・変化量バー・ファイル名（表形式） |
| 4. 対象コミット一覧 | コミット系モードのみ |
| 5. 差分明細 | ファイルごとの見出し ＋ ハンク見出し ＋ ` ```diff ` ブロック |
| 付録 | 生の `git diff`（`<details>` で折りたたみ。`--no-raw` で省略可） |

```markdown
### [1/3] `src/main.c`

- **状態**: 変更 (M)
- **増減**: 追加 +10 行 / 削除 -2 行

**@@ ハンク1 — 旧: 8 行目から 3 行 → 新: 8 行目から 4 行 @@**
```

- 追加行が緑、削除行が赤で表示されます（GitHub / GitLab / Backlog などの `diff` シンタックスハイライト）。
- `--md-linenos` を付けると、差分行の先頭に旧／新の行番号を併記します。
- 差分本文にコードフェンス（` ``` `）を含むファイル（Markdown 等）でも崩れないよう、
  フェンスにはバッククォート **4 個** を使用しています。

### 4.3 Excel（xlsx）

`<出力先>/<接頭辞>_<モード>_<YYYYMMDD_HHMMSS>.xlsx`

| シート | 内容 |
|--------|------|
| **サマリ** | 実行条件（日時・リポジトリ・モード・比較対象・実行コマンド等）と集計値 |
| **ファイル一覧** | No / 状態 / 状態コード / 追加行 / 削除行 / 変更行合計 / 種別(テキスト・バイナリ) / ファイル(新) / ファイル(旧) |
| **差分明細** | No / ファイルNo / ファイル / ハンク / 旧行番号 / 新行番号 / 区分 / 記号 / 内容 |
| **コミット履歴** | No / コミット / 日時 / 作成者 / 件名 |

- 追加行は緑、削除行は赤、ハンク見出しは青、属性情報は灰で色分け
- 見出し行のウィンドウ枠固定 + オートフィルタ設定済み（区分やファイルで絞り込み可能）
- 内容列は等幅フォント（Consolas）でインデントが崩れません

CSV 形式（`-x csv`）を選んだ場合は、シートごとに 4 本の UTF-8 BOM 付き CSV を出力します。

### 4.4 利用ガイド Excel（使い方マニュアル）

`<出力先>/<接頭辞>_使い方ガイド_<YYYYMMDD_HHMMSS>.xlsx`

詳しい利用方法をまとめた 9 シート構成の Excel です。**全シート Meiryo UI フォント**で作成しています。

| シート | 内容 |
|--------|------|
| **表紙・概要** | できること / 3 ステップで使いはじめる / 本ガイドの構成 / 動作要件 |
| **セットアップ** | 導入手順（STEP 1〜5）/ 依存コマンドと導入方法 / 動作確認 / つまずきやすい点 |
| **モード一覧** | 9 モードの比較元・比較先・実行される git コマンド・用途 / 迷ったときの選び方 |
| **オプション一覧** | 全オプションを分類・短縮形・引数・既定値・説明で一覧化 |
| **使用例** | 目的別の 25 例。コマンドをそのままコピーして使えます |
| **出力ファイル** | 出力物の一覧 / Excel のシート構成 / 色分けの凡例 |
| **レポートの見方** | 差分明細の読み方（見本付き）/ 記号と色 / 状態コード / Markdown の見方 |
| **FAQ・トラブル対処** | よくある症状と対処 17 件 / 終了コード / 制限事項 |
| **用語集** | ワークツリー・ステージ・ハンク・三点比較などの用語解説 |

- 見出し帯（濃紺）＋ ゼブラ模様 ＋ 細罫線で構成し、シートごとにタブ色を設定
- 表は見出し行のウィンドウ枠固定 ＋ オートフィルタ付き
- 追加=緑 / 削除=赤 / ハンク=青 / 属性=灰 の実際の色サンプルを掲載
- 印刷は A4 横・横方向に 1 ページ幅で収まる設定（ヘッダー・フッターにページ番号）
- 既定では差分レポートと同時に出力されます。不要な場合は `--no-manual`、
  ガイドだけ欲しい場合は `--manual-only`（git リポジトリ外でも実行可）

## 5. 動作確認済みの条件

- リネーム／コピー検出（`R100` などの類似度付きステータス）
- バイナリファイル（`Binary files ... differ`）
- 新規追加・削除・モード変更のみのファイル
- 日本語ファイル名、空白を含むファイル名（`core.quotepath=false` 指定済み）
- CRLF 改行、タブを含む行、400 文字超の長い行
- XML 特殊文字（`< > & " '`）を含むソース（xlsx 内で正しくエスケープ）
- コミットが 1 件も無いリポジトリ（空ツリーとの比較に自動フォールバック）
- 最初のコミットや履歴数を超える `-n` 指定（空ツリーとの比較に自動フォールバック）
- 24,000 行規模の差分（処理時間の目安: 数秒）
- Markdown 内にコードフェンス（` ``` `）を含むファイルの差分（4 個フェンスで保護）
- bash 5.2 以降での `${var//&/...}` の仕様変更（`\&` でエスケープ済み。bash 5.1 でも同一結果）

## 6. 補足・制限事項

- パス名に改行を含むファイルは正しく扱えません（`-z` 出力を行単位で解析しているため）。
  通常の運用では発生しません。
- 差分明細シートは既定で 100,000 行を上限としています（Excel の実用上の制約）。
  上限を超えた場合は末尾に省略行数が記録されます。`--excel-max-rows` で変更可能です。
- 画面の罫線は UTF-8 ロケールを検出して自動選択します。`LANG=C` などでは自動的に
  ASCII 文字に切り替わります（`--ascii` で明示指定も可能）。
- 全角文字の桁揃えのため、非 UTF-8 ロケール環境では awk のみ `C.UTF-8` などの
  UTF-8 ロケールで起動します（出力エンコーディングは常に UTF-8）。
- Markdown の表セル内に含まれる `|` は `\|` にエスケープします。
- 利用ガイド Excel の生成には `zip` または `python3` が必要です。どちらも無い環境では
  警告を表示してスキップします（差分レポート側は CSV へフォールバックします）。
- 利用ガイド Excel は実行のたびに新しいタイムスタンプで生成されます。毎回不要な場合は
  `--no-manual` を指定し、必要なときだけ `--manual-only` で作成してください。

## 7. 終了コード

| コード | 意味 |
|--------|------|
| 0 | 正常終了（差分の有無に関わらず） |
| 1 | 引数エラー、リポジトリ不正、参照解決失敗、出力失敗など |
